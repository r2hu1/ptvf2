## Tech Stack

- **Framework:** Next.js 16 (App Router), React 19
- **Language:** TypeScript 5.9
- **Styling:** Tailwind CSS v4 (dark-only, oklch colors, @theme inline)
- **Animations:** Framer Motion (layout animations, AnimatePresence)
- **UI:** shadcn/ui primitives (Button, Card, Skeleton, Sonner, Tooltip) via radix
